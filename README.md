# HGTEAM — conceito de redesign

Landing page demonstrativa para Hugo Gouveia, feita com React, Vite, CSS responsivo e Motion. O visual usa uma foto real de Hugo e prioriza a leitura no celular.

## Executar localmente

```powershell
npm install
npm run dev
```

Para gerar o build de produção:

```powershell
npm run build
```

`/mobile-preview.html` abre uma prévia da página em uma área de 390 × 844 px.

## Conteúdo público usado

Os três pares de antes e depois e a lista de soluções (e-book, consultoria online e acompanhamento presencial) foram consultados no [site atual do HGTEAM](https://hugo-silk-zeta.vercel.app/). As fotos foram compactadas para uso na página, sem alterar o conteúdo visual. Não foram atribuídos prazos ou resultados numéricos às comparações.

## Uso

Este é um conceito de redesign para portfólio, não uma página oficial do HGTEAM. Os links de WhatsApp usam mensagens diferentes para e-book, consultoria online e acompanhamento presencial. Antes de qualquer uso oficial, confirme com Hugo o número, CREF, autorização das fotos, local de atendimento e condições dos serviços.

Não há preços, depoimentos ou resultados inventados.
